# Flappy Bird - Python Project

This is a simple Flappy Bird game that I made as a beginner Python project for college.

I wanted to make something small that would help me understand how Python can be used to create an actual game. I used Pygame for the graphics, keyboard controls and game window.

## What the game has

- A bird that can fly when I press the SPACE key
- Gravity that makes the bird fall down
- Pipes with randomly generated gaps
- Collision detection between the bird and pipes
- A score that increases when the bird passes a pipe
- Clouds and a simple background
- A game over screen
- An option to restart the game

## Controls

| Key | Action |
|-----|--------|
| SPACE | Make the bird fly |
| R | Restart after game over |
| Q | Quit the game |
